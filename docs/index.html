01 GET STARTED

Add Nucleus to your project.

Use a source checkout in your CMake build, or build and install a reusable package.

1 Add the library from your project root.

Terminal
git submodule add https://github.com/WenchaoHuang/Nucleus.git third_party/nucleus

2 Link the public CMake target.

CMakeLists.txt
cmake_minimum_required(VERSION 3.18)
project(my_app LANGUAGES CXX CUDA)

add_subdirectory(third_party/nucleus)
add_executable(my_app main.cu)
target_compile_features(my_app PRIVATE cxx_std_20 cuda_std_20)
target_link_libraries(my_app PRIVATE Nucleus::nucleus)

1 Build and install to a prefix of your choice.

Terminal
git clone https://github.com/WenchaoHuang/Nucleus.git
cd Nucleus
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
cmake --install build --config Release --prefix /path/to/nucleus

2 Find the package in your application.

CMakeLists.txt
cmake_minimum_required(VERSION 3.18)
project(my_app LANGUAGES CXX CUDA)

find_package(Nucleus CONFIG REQUIRED)
add_executable(my_app main.cu)
target_compile_features(my_app PRIVATE cxx_std_20 cuda_std_20)
target_link_libraries(my_app PRIVATE Nucleus::nucleus)

3 Point CMake to your installation when configuring.

Terminal · application root
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/nucleus

02 FIRST PROGRAM

A complete trip to the GPU.

Allocate an array, run a kernel, and copy the result back. Save this as main.cu alongside the CMake configuration above.

01 Allocate→02 Fill & launch→03 Copy & sync
</> main.cu View complete example+
C++ / CUDA
#include <vector>
#include <nucleus/array.h>
#include <nucleus/device.h>
#include <nucleus/device_span.h>
#include <nucleus/runtime.h>
#include <nucleus/stream.h>
#include <nucleus/launch_utils.cuh>

__global__ void scale(dev::Span<float> values)
{
	CUDA_for(i, values.size());
	values[i] *= 2.0f;
}

int main()
{
	if (ns::Runtime::devices().empty())
		return 1;

	auto * device = ns::Runtime::device(0);
	auto & stream = device->defaultStream();
	constexpr size_t count = 1024;
	constexpr unsigned int blockSize = 256;

	ns::Array<float> values(device->defaultAllocator(), count);
	std::vector<float> result(count);

	stream.fill(values.data(), 1.0f, count)
		.launch(scale, ns::ceil_div(count, blockSize), blockSize)(values)
		.memcpy(result.data(), values.data(), count)
		.sync();

	return result.front() == 2.0f ? 0 : 1;
}

Ownership and completion. The fill, kernel, and copy run in order on one stream. The final sync() completes the copy before the host reads the result and the arrays leave scope. Views borrow memory; callers must keep resources alive until their GPU work completes. See the resource and execution contracts ↗.

Compile with nvcc. The launch_utils.cuh header defines device code and belongs in .cu translation units. A CUDA-capable GPU is required to run the example.

Terminal · application root
cmake -S . -B build
cmake --build build --config Release
